# 暖褐极简编辑式设计系统

## 参考与边界

视觉参考为 [Brown Modern Minimal Interior Design Presentation](https://www.canva.com/design/DAHXDP7ODcY/bPO0OqHrlo4tjgf1rXu7Zg/edit?ui=eyJBIjp7fX0)。已从原始 Canva 页面观察 16 页网格与封面；参考截图保存在 `assets/reference-design/canva-overview.png` 和 `canva-cover.png`。仅提取色彩、字阶、摄影与构图，不复制模板照片、品牌、年份、项目履历或业务文案。新配图使用用户提供的合适素材或原创生成图片。

用户已于 2026-10-04 明确批准中文样稿，并授权正式接入和安装。批准后的本地参考包括 [封面](../assets/reference-design/approved-cover.jpg) 与 [阅读页](../assets/reference-design/approved-reading.jpg)；它们用于保持视觉方向，不复制其示例业务。适用于品牌介绍、作品集、生活方式、空间与文旅、公司与工作室介绍以及文化提案，摄影题材随实际内容变化。

## 画布与字阶

- 16:9 画布；以 1920 × 1080 实现时，外边距从 48 px 起，采用 12 栏对齐。满版照片可出血，文字仍留清楚的安全边距。
- 暖米白 `#EFEEEA`（239, 238, 234）为主要纸色，深褐 `#4A4235`（74, 66, 53）为标题与深色面；两色已依据源参考截图校准。灰褐 `#7B7265` 为次级文字。整稿使用同一组色值，不逐页换色。
- 大块空白参与构图，细线只用于分区、注释和页码秩序。信息量以内容决定，不把留白补成卡片。
- 源参考的正文为 Open Sauce，无衬线；封面及大短句使用 Noto Serif Display。中文正文采用本地 `PingFang SC`、`Microsoft YaHei`、sans-serif；中文衬线大字采用 `Songti SC`、`STSong`、serif。英文可使用已安装的原字体，否则采用本地替代，不要求下载字体或加载远程字体。
- 正文细至常规字重，以字号、位置和空间建立层级。衬线仅用于封面或少量大短句，普通标题和说明保持无衬线。中文按语义断行，不机械复制英文大小写、字距与字数。

## 构图选择

按叙事选择下列结构，不要求每稿集齐：

| 页面任务 | 主要构图 |
|---|---|
| 封面与定位 | 左半深褐、右半真实照片；大标题可落在下部。源参考的上下双标题可简化为一个中文主标题，不机械重复。 |
| 章节或主张 | 上部简短标题，下部通栏照片，以宽阔水平线组织空间。 |
| 目录或介绍 | 窄侧栏承载编号与小字，大幅照片占其余页面。 |
| 解释或故事 | 左侧文字，右侧竖幅照片；图文数量不必对称。 |
| 服务与能力 | 两至三组短文，下方一条通栏照片或相邻摄影条带。 |
| 案例与场景 | 三至五张照片形成 contact sheet；尺寸与间距有主次，短标签独立可编辑。 |
| 流程与路径 | 上方全景照片，下方深褐流程带；步骤以文字、编号和细线表达。 |
| 观点与收束 | 柔焦满版照片配大短句；选用安静区域承载文字，通过照片本身的明暗保证对比。 |
| 细节与留白 | 一张非对称小幅细节图，配简短说明和大面积空白。 |

本风格按已批准方向独立安排页头、封面尾页、字阶与边距，页头采用本包 `header_system: style` 与页头模板，不继承六种预设。正式构建可选全部共享布局；常用 `editorial` 的字段见 [共享契约](../../white-blue-slides/references/deck-format.md#editorial编辑式图文页面)。阅读型按内容组织信息，不固定四种分区；`layout: reading` 只是可选结构。新增布局进入共享层，风格只决定外观，不用无效字段模拟支持。

## 摄影与组件

摄影采用真实尺度、暖调低饱和、斜阳或柔和自然光与轻颗粒；石、木、亚麻、陶等材质可作为内容相关的场景与细节。照片可以是室内空间、工作场景、人物动作或物件，不要求所有主题都转成室内设计。

照片使用直角边界，允许大幅裁切、条带与局部特写。图表、流程、标签和数据使用可编辑页面组件，采用褐色及中性色建立对比。避免圆角卡片、厚阴影、渐变背景、玻璃效果和拟物图标；不为铺满画面增加装饰元素。
