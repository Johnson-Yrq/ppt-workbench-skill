# 配图与纹理流程

本包采用自然彩色商务摄影，`image_background: "scene"`；大理石为单独的黑白纹理。先读 [设计系统](design-system.md)，再用当前页的真实主题、动作和空间准备素材。图片内不放可编辑业务信息，不复用 Canva 参考中的原照片。

1. 优先使用用户已提供且授权的合适素材。缺少合格素材且有生图能力时，主动生成与当前内容有关的独立照片，不为模板空位索取无关图片。
2. 商务摄影保留真实肤色、衣物色和环境色，以柔和窗光、自然交流和可信工作动作统一气质。人物、镜头距离和场景应有变化，不把同一个脸或房间反复当成不同内容。
3. 独立人物使用方形或竖幅照片，保留完整头部及手势的安全裁切区域；姓名和职能写入 `people.items[].name / role`。生成主体为虚构人物，不能冒充真实员工、创始人或客户。
4. 场景照片按页面所需横纵比例取景，保留必要背景，不执行抠图、边缘渐隐或纸色映射。不向照片内加入大理石框、图标、标题、可读界面、数字、水印或品牌。
5. 大理石单独生成：正视天然石材近景，黑白矿纹有自然流动与颗粒变化，光线均匀。避免金色纹路、台面透视、物品、倒角石板和文字；提供完整纹理，由主题决定窄条、底衬或低透明度背景的位置。
6. 标题、段落、图注、图表、来源、数字和联系信息全部写入可编辑字段。纹理只承担材质装饰，不模拟数据或流程；图表与关系结构使用共享组件。
7. 每张业务图片记录 `src / alt / brief`；通过共享 `prepare_images.py` 生成逐图提示词与资源清单。记录生成方式和原文件位置，使用本地文件构建并内嵌资源。

内置摄影与纹理提示词见 [image-style.txt](../assets/image-style.txt)。封面、目录、纯文字、数据或关系页可以不使用业务照片；大理石装饰不构成“已有真实业务照片”的事实依据。

## 本次已批准样稿

项目 `examples/monochrome-marble` 当前记录九项原创生成素材：一张大理石纹理、三张独立人物肖像，以及五张公司、行业、服务和市场场景照片。资产位于 [images](../assets/images)，来源采用内置 imagegen。原始图像保留，页面使用本地 WebP 副本；不借用参考模板的照片。

`image-prompts.json` 保存逐图完整提示词，`image-sources.json` 保存原始路径、素材路径、生成方式与出处说明。生成照片不是真实客户案例或真实团队证明，砚序咨询、成员身份、2026 计划和图表数字均为示意。真实项目缺少必要事实时，保留缺口并完成不依赖它的部分，不把生成素材当作事实补齐。

本包为 **ready / 1.0.0**。用户于 **2026-10-05** 明确回复「采用，安装，并提交」，批准当前中文样稿方向、正式接入、安装及相关改动提交，见 [批准记录](source-notes.md#批准状态与交付位置)。正常制作按真实内容准备素材，不再要求确认同一视觉方向；未来独立新方向仍按其自身批准要求处理。安装完成状态以实际验证及主任务报告为准。
