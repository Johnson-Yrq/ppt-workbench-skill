# 黑白大理石商务设计系统

本包从用户在 Chrome 中打开的 Canva 商业计划参考提取视觉规则，完整来源与十五页转译见 [来源说明](source-notes.md)。参考截图用于设计观察，不作为成品页或业务素材复用。原作者与原字体未确认；Georgia 和 Songti SC 是本地近似选择，不宣称还原了模板字体。

## 视觉语言

| 项目 | 本包规则 |
|---|---|
| 画布 | 1920 × 1080、16:9，内容由共享播放器等比显示 |
| 基础色 | 白 `#FFFFFF` 与近黑 `#0B0B0B`；辅助灰保持文字、线条和图表的区分 |
| 字体 | Georgia、Times New Roman、Songti SC、STSong 等本地衬线回退；不下载远程字体 |
| 标题 | 高对比大字与自然中文断行；内容标题约 94–112px，海报与封面更大，实际以主题 CSS 为准 |
| 正文 | 常规约 30–34px、舒展行距；阅读稿通过内容组织或拆页增加信息，不整体缩字 |
| 留白 | 常规横向边距约 110px；正文、标题、照片留出独立区域 |
| 页头 | 自主页头，短横线与页码独立呈现；主体布局已有标题时不重复 |
| 形状 | 直角照片、细线与克制的图标；不加圆润卡片、厚阴影或玻璃面板 |
| 大理石 | 天然黑白矿纹，使用单独原创纹理；可作为窄边条、浅背景、局部带或照片错位底衬 |
| 摄影 | 自然彩色商务摄影，柔和窗光、可信动作、完整人物与现场背景 |
| 图表 | 灰阶系列与明确单位、来源；数字、类别和解释均为可编辑内容 |

黑白系统组织页面，大理石提供有限的材质层次，照片保留自然颜色。不要给人物和场景统一灰阶，也不要把纹理放大到遮蔽正文或制造虚假的数量含义。

## 页面表面

| `surface` | 外观与适用位置 |
|---|---|
| `light` | 白底黑字，用于目录、常规叙事、图表或摄影页 |
| `dark` | 近黑底白字，用于有意强调的叙事、指标或联系页 |
| `marble-light` | 白底与低透明度大理石纹，保留足够空白和文字对比 |
| `marble-dark` | 近黑底与克制纹理，适合能力列表或章节节奏变化 |
| `inset-dark` | 外围白边、内嵌黑色面板，用于章节或简短声明 |

表面名称来自本包 manifest，不使用未声明的变体。某页的窄大理石边或照片底衬是布局的主题处理，不应被误写成额外 surface。页码、图标、图表、来源文字和编辑控件均需随深浅表面保持对比。

## 代表页面与共享结构

| 来源页 | 共享结构 | 本方向的转译 |
|---|---|---|
| 01 | `cover` | 左侧大标题，右侧大理石竖条 |
| 02 | `side_index` | 十二项目录，序号和标题保持独立文本 |
| 03 | `type_poster` | 左上标题、左下正文，以留白组织叙事 |
| 04 | `editorial_columns`，image / text | 左照片与错位纹理，右标题和说明 |
| 05 | `editorial_columns`，text / people | 左标题，右侧三名成员纵排，浅大理石背景 |
| 06 | `editorial_story` | 深色页，左侧三项叙事，右侧宽图与下置标题 |
| 07 | `editorial_columns`，三个 chart 栏 | 三组图表并列，标题解释邻近，底部大理石带 |
| 08 | `editorial_columns`，groups / text | 左侧三个图标说明组，右侧大标题 |
| 09 | `type_poster` | 白边内嵌黑色面板，简短大字声明 |
| 10 | `editorial_columns`，text / image | 左文右图，浅大理石背景 |
| 11 | `editorial_columns`，text / groups | 左大标题，右侧五个图标标题，深色纹理背景 |
| 12 | `editorial_columns`，gallery / text | 左侧两张照片上下叠放，右侧标题说明 |

上述顺序用于已批准的代表样稿，不要求真实稿复刻十五页。两种用途均可选用 20 种共享构图与 48 个 profile；按实际关系和数量决定结构。独立图表或图表栏只在有可靠数据时使用，不能从模板的曲线、图标或大数字推断事实。

## 可编辑内容与素材

图表、目录序号、姓名、角色、联系信息、页码与段落保持独立节点。`groups` 为无序条目，2–6 项，每项 title 必填，text 与有效 icon 可选；不要用步骤号假装联系或能力分组。标题独栏遵守共享合同，不以空字符串或空数组制造版式。

照片不烘焙边框、纹理底衬、文字或装饰；构图与裁切交给页面。天然大理石纹作为独立本地资源嵌入离线 HTML，不依赖网络。正文压在纹理上时，以较低纹理透明度和清晰的文字区域保证阅读。
