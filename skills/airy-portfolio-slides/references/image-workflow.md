# 配图流程

本风格以真实尺度的自然摄影组织叙事。旅行、食物与相聚是开发样稿的题材，真实项目应改为与用户内容相关的照片；纯文字封面和主张页不必配图。多数适合配图的内容页主动准备独立素材，让不同镜头承担全景、细节、人物与关系等不同作用。

## 素材与事实边界

先复用用户提供且适合本页内容的素材。需要新图时优先用可直接调用的内置生图工具；没有内置工具时参考共享 [生图 API 流程](../../white-blue-slides/references/image-api.md) 或人工供图，不静默切换付费服务。缺少必需素材时继续独立的文字与布局工作，并保留依赖它的缺口。

Canva 截图仅供观察结构与视觉，不从截图提取照片、人物、品牌或占位文案作为成稿资产。已批准样稿为虚构摄影工作室「拾光影像」准备 14 张原创生成图片，并在讲稿中注明示例性质；提示词记录在项目 `examples/airy-portfolio/image-prompts.json`，本包素材位于 `assets/images/`。不得把生成场景称作真实客户项目、已发生的活动、指定人物或摄影师的真实作品。

真实作品集优先使用真实作品与用户提供的事实。若缺少必要作品，不能用生成图片补造履历；明确区分概念示例和真实记录。

## 每张照片的简报

以本包 `assets/image-style.txt` 为基底，逐张补充：

- **对象与作用**：本页具体地点类型、食物、器皿、工作动作或人物互动，以及照片支持的叙述。
- **镜头与光线**：全景、中景、近景或细节；自然光、环境光及真实透视。彩色摄影保留克制而真实的颜色，幕后人物可选黑白。
- **画幅与裁切**：横图、竖图或方图，说明必须保留的人物面部、手势、食物主体、道路走向和画面留白。拼图中改变镜头尺度，不只换裁切。
- **文字边界**：照片不包含标题、品牌、页码、图注、水印或事实数据；这些信息由可编辑页面表达。

只生成独立照片，不生成整页幻灯片或预先拼好的多图位图。三图作品页使用三张独立图片，上下双图同样各用一个资源。不得复制一张图片或用同图的不同裁切冒充多项作品。

## 数据、颜色与嵌入

按所选共享布局的真实图片字段填写独立 `src / alt`，需要说明时使用可编辑 `caption`。`editorial_columns` 的图片嵌套于 image、gallery 或 people 栏中；图片数量和行高权重遵循 [共享布局合同](../../white-blue-slides/references/shared-layouts.md)，不套用旧 reading 布局的数量限制。

使用 `image_background: "scene"` 保留照片自身背景；不做纸色映射、淡边融合、全局 multiply 或整稿灰阶。页面近白与照片色彩并置，统一来自镜头语言、光线和排版。优先保留原始素材，裁切时保住语义主体。

生成、查看、裁切和嵌入素材属于配图工作，不延伸成默认的逐页截图或整稿验收。普通成稿导出与检查由用户完成；明确委托导出或检查时完成对应范围。
