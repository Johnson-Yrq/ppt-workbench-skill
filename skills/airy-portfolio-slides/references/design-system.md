# 留白衬线影集设计系统

## 来源与转译

参考 Canva 模板 **Presentación Portafolio Estudio de Fotografía Simple Minimalista Blanco**，作者 **Mica Crocce - Creare DG**。十页截图与对应结构见 [来源记录](../assets/reference-design/source-notes.md)。提取近白底、黑色衬线字、宽阔留白、细线页脚和自然摄影的视觉关系，不复制模板照片、品牌或占位文字。

原模板字体名称未知；以下为本地离线中文的替代方案，不宣称与原字体相同。中文转译样稿已于 **2026-10-05** 获用户明确采用，并获正式接入与安装批准；本包以 **ready / 1.0.0** 供正常制作，同一方向不重复确认。

## 画布、色彩与字体

- 16:9、1920 × 1080。主体采用直角图框，图框与外缘之间留出宽阔空白；页面安静但不通过删除必要信息制造留白。
- 纸色 `#FAFAFA`，为参考截图经 ICC 转换到 sRGB 后的本地采样近似；黑色文字与细灰线建立层级。不把截图采样宣称为 Canva 原始设计令牌。
- 标题使用本地 `Georgia`、`Times New Roman`、`Songti SC` 等衬线字体与 serif 后备；中文保留自然字形和语义断行，不按拉丁大写的字距等比例拉开每个汉字。正文保持适合中文的行距与清楚字阶，不加载远程字体。
- 默认以近白背景贯穿页面；色彩主要来自照片。旅行图保留蓝灰、草木与土色，食物图保留食材和器皿的自然色，聚会图允许暖光与暗部。幕后人物可用黑白；不整稿灰阶，也不机械统一成棕色滤镜。
- 清单声明 `light / dark` 两种页面表面，样稿使用 light；dark 是同一主题的深色延伸，只在内容需要时使用，不规定明暗交替。
- 内容页以细横线收束，下方居中安排动态页码与品牌。页码来自实际页序，品牌来自项目数据；封面保留纯净的居中文字组。

## 构图语法

| 页面任务 | 视觉组织 | 共享结构 |
|---|---|---|
| 封面 | 居中衬线大标题，短眉题与副标题，上下宽阔留白 | `type_poster`，`variant: cover`、`placement: center` |
| 叙事主张 | 居中短句，依靠文字尺度与空白表达停顿 | `type_poster`，`variant: statement`、`placement: center` |
| 理念 | 文字组压在右下，标题、短文与少量条目独立可编辑 | `type_poster`，`variant: statement`、`placement: bottom-right` |
| 关于 | 左侧竖幅幕后照片，右侧文字落在较低位置 | `editorial_columns` 的 image / text，text 的 `align: end` |
| 旅行项目 | 左侧上下两幅风景，右侧完整叙述 | `editorial_columns` 的 gallery / text |
| 三图作品页 | 一张大图与一列两图，或三张等宽竖图 | `editorial_columns` 的 image / gallery 或三个 image 栏 |
| 食物拼图 | 左侧两张不等高图片与右侧大图，镜头尺度各有作用 | 单列 gallery 使用 `row_weights`，旁接 image 栏 |
| 聚会叙事 | 左下文字与右侧照片，再用三幅照片呈现人、餐桌与互动 | `editorial_columns` 的 text / image 与多图页面 |

以上是示范语法，不是每份稿的固定章节。新项目按内容选择共享结构；源模板没有联系页，不为复刻它而编造联系信息或强加联系尾页。

## 共享字段与独立外观

精确字段见共享 [文字海报与编辑分栏](../../white-blue-slides/references/shared-layouts.md#文字海报与编辑分栏)。居中文字、右下文字与图集都使用共享结构；风格只决定外观、字阶和留白，不把页面烘焙为一张图。

纯作品页可用 `editorial_columns.show_title: false` 隐藏展示态标题和副标题，必需 `title` 仍保留语义并在编辑态显现。单列 gallery 可用 `row_weights` 分配上下图高；图片是独立资源，各自可换。标题、正文、条目、图注和页码均由页面承载，不能烧进照片。

本包使用独立 `header_system: style` 与 `header.html`，不继承六种页头预设。标题已在主体布局呈现时页头不重复输出；页脚、图框和正文必须共享清楚的安全边距。阅读型沿用本风格的页面语言，长文按语义拆分，而非压小字号塞进样稿图框。

避免圆角卡片、厚阴影、玻璃质感、装饰渐变、无关图标与立体微缩模型。自然照片须保留真实尺度、光线、纹理与裁切重点，不因模板留白较大就使用无关照片填空。
