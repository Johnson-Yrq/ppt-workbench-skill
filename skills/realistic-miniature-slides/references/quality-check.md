# 写实微缩用户检查参考

下列成稿检查供用户自行使用或明确委托 Agent 检查时参考，不是默认制作流程。默认完成 HTML 与配图后交付，导出与检查由用户完成，见共享 [交付规则](../../white-blue-slides/references/export.md#默认交付与职责)。

## 内容计划

- 风格与用途来自用户选择或已确认项目；根字段显式记录 `real-miniature` 和 `speech / reading`。
- `--check-plan` 通过；每页结论、图片作用、分组处理与原始要求对应。缺失事实保留待确认，不借用示例数字。
- 阅读型页面保留独立理解所需的解释、依据和边界；布局与图片比例按内容决定，文字足以说明时不强加图表。多图各有内容作用。

## 逐页视觉

- 封面、正文、图标、流程、表格和尾页均为暖灰、石墨、灰蓝与鼠尾草绿主题；页面信息区干净，边界 6px 小圆角，页码至少 36px。
- 图为 35–45° 微缩视角、真实 PBR 木材／矿物／金属／织物，灯光柔和有方向；人物有细致表情和可信手部。无无脸人偶、玻璃展台、金属金边或无关巨大屏幕。
- 配图各表面无文字、数字、伪文字及品牌；标题、标签、数据和解释可编辑。前景人物、基座、道具和接触阴影完整，不靠过大空白冒充图区。
- 图框与图片元素的面积通过后，继续查看场景本体是否展开、阶段说明是否拥挤；检查背景四边和主体间露出的底色，不能有明显矩形底或伪透明棋盘格。
- 同层级对齐统一，轻量强调不产生突兀卡片。文字在安全区内，无溢出、相互覆盖或低对比小字；图表与说明对应，来源清楚。
- 若选用 `layout: reading`，按其 composition 核对图片与模块数量；其他布局不套用该分区合同。架构文字逐一对齐真实模块。

## 功能与交付

运行共享 `audit_deck.cjs`，核对翻页、缩略图总览、文字编辑、保存重开、讲稿、移动端适配、全屏与打印；带图表时核对数值编辑、保存重开和离线渲染。检查网络请求，成品无需 CDN 或外部图片。

用户可结合截图查看背景、层次、占幅和图文对应，并自行查看导出的实际文件；Agent 不自动开展这些步骤。

## 开发检查

修改本包的运行代码、主题或共享工具时，按共享 [开发与维护检查](../../white-blue-slides/references/quality-check.md#开发与维护检查)执行适用测试，使用受影响的演讲型与阅读型案例，保留其他风格的外观与功能。仅修改说明文档不触发成稿自检与导出。

普通制作交付独立 HTML，不把缺图占位稿冒充成品。过程文件和图片简报用于后续修改，不增加用户批准节点。
