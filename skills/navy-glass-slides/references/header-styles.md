# 海蓝玻璃的六种页头

本风格在 `assets/style.json` 声明 `header_system: "preset-six"`。以下六种页头属于海蓝玻璃的可选预设，色彩、字阶与细线沿用本包设计系统；它们不是新增风格的全局要求。

根字段 `header` 设置内容页默认值，单页 `header` 可覆盖；默认 standard。封面、尾页与在主体中安排标题的 editorial 页面使用自身页头结构，不设置单页 `header`。排布参考见共享资源的 [对比图](../../white-blue-slides/assets/header-styles.png)，图中的素白蓝调颜色不作为本风格配色。

| `header` | 排布 | 适合 |
|---|---|---|
| `standard` | 章节标签、主标题、副标题，右上页码 | 常规信息页 |
| `compact` | 章节与标题同排，小页码 | 密集信息、表格、架构 |
| `rail` | 页码置左，以竖线连接标题区 | 议程、章节和步骤 |
| `band` | 标题区置于通栏浅底 | 重点结论或章节起始 |
| `aside` | 标题在左，副标题在右 | 短标题搭配解释 |
| `ghost` | 浅色大页码位于标题后方 | 简洁主张或留白页 |

按内容选择，不另外询问用户；明确指定时照办。同一章节保持一致，单份稿一般不超过三种。该建议只约束本风格的预设使用，不影响主体布局选择，也不因 speech／reading 用途改变页头体系。
