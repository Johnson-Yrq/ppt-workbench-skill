# 配图流程

本风格以黑白建筑摄影承担空间、材质和结构信息。主动为多数适合配图的内容页准备独立照片，按关系组合大幅主图、竖图、肖像队列、细节与多图拼贴；纯文字封面、数字章节页以及用户明确指定无图的页面保持无图。摄影数量来自内容作用，不因大纲没有写“配图”就只做文字，也不重复同一文件或裁切同图来凑数量。

## 素材来源与真实边界

先查看并复用用户已提供、适合当前内容的素材。需要新图时优先用可直接调用的内置生图工具，生成后保存在项目中；没有内置工具时，按共享 [生图 API 流程](../../white-blue-slides/references/image-api.md) 或人工供图继续，不静默切换付费服务。缺少必需素材时只暂停依赖它的部分，继续独立的文字与布局工作。

Canva 截图仅用于识别构图与视觉，不复制其中的建筑、头像、图纸、品牌或占位文案进样稿。中文样稿使用原创概念照片与明确标注的虚构建筑工作室资料；它们不是客户项目、真实员工、建成工程或业绩。真实团队介绍应使用用户提供的人像与身份，不能拿生成头像冒充指定人员。

## 每张照片的简报

在本包 `assets/image-style.txt` 的基底上补充本页独有内容：

- **对象与关系**：建筑体量、立面、天窗、梁柱、庭院、室内光线、材料细部、工作动作或肖像，以及它解释的观点。
- **镜头与明暗**：真实摄影尺度、自然光、明确透视、黑白层次；改变远近和视角，避免整稿都是同一种仰拍幕墙。
- **画幅与裁切**：通高竖图、横向画面、正方形拼贴或肖像；说明必须完整保留的建筑线条、人物头部及需要留白的位置。
- **数据与文字边界**：照片不包含标题、章节数字、姓名、角色、Logo、水印、可辨认的虚构尺寸或事实数据。真实工程图纸或产品界面由用户提供；概念设计只呈现无文字的线条或物件，不充当施工依据。

只生成独立照片素材，不生成幻灯片、不把多张图预先压成拼贴位图。八图拼贴使用八张不同图片，各自独立可换；人物队列每人独立图片，并在页面写姓名与角色。显示器构图只准备屏幕里的相关图片，提示词明确不画设备、边框或支架；外框由共享 `frame: "monitor"` 结构绘制，避免把图框与所有文字烧进一张图。

## 数据与嵌入

单图或多图使用所选共享布局的真实字段，包含独立 `src / alt`；需要图注时用 `caption`，保持可编辑。`editorial_columns` 的图片可以嵌套在 image、gallery、people 栏中，按共同资源处理导出供图清单和内嵌文件；数量遵循共享 [布局合同](../../white-blue-slides/references/shared-layouts.md)，不套用旧 reading 的 1–3 张上限。

照片保留现场空间、材质与自然光背景，使用 `image_background: "scene"`；不做模型纸色映射、淡边或 multiply 底色消除。主题可以统一为黑白显示，但仍需选择本身明暗与层次合适的图片；保留原始素材。新图准备、裁切、嵌入及按图像工具要求查看属于素材处理，不延伸为默认的逐页截图、整稿内容审查或重复验收。正式成稿导出与检查由用户完成。
