# 原色建筑编辑式设计系统

## 来源与转译

参考 Canva 模板 **Presentación Arquitectura Minimalista Colorida**，作者 **Belén Creativa**，模板 ID `EAFYtFCow0M`。十页参考截图与逐页结构说明见 [来源记录](../assets/reference-design/source-notes.md)。提取的是白底黑字、极窄展示大字、错位栏目、黑白摄影与四色数字章节节奏，不复制照片、文案、姓名或客户信息。

原模板字体名称未获确认。下文是适合本地离线中文的替代方案，不宣称与原字体相同；中文按语义断行，不照搬拉丁字母的横向压缩、大小写或占位文案密度。中文转译样稿已于 **2026-10-05** 获用户明确采用，并获正式接入与安装批准；本包以 **ready / 1.0.0** 供正常制作，同一方向不重复确认。

## 画布、色彩与字体

- 16:9、1920 × 1080。白色内容页以直角栏和大面积空白组织信息，图像栏可贴边；文字保留清楚的页边距和栏间距。
- 底白 `#FFFFFF`、近黑 `#050505`。四色章节背景按截图色彩空间校准为芥末黄 `#CEBA2F`、蓝 `#2F8DD1`、红 `#CE3130`、青柠绿 `#9CCF34`；它们是本地转译色值，不宣称来自原模板的设计令牌。
- 章节页每页使用一种平涂颜色与一个巨大的黑色数字；颜色不用于暗示未定义的数据含义。普通内容页以黑白为主，不给每个分组涂一块彩底。
- 展示字体优先本地 `Bodoni 72`、`Didot`，中文使用 `Songti SC`、`Noto Serif CJK SC` 及 serif 后备。正文使用无衬线栈 `Arial Narrow`、`Helvetica Neue`、`PingFang SC`、`Microsoft YaHei`、`Arial` 与 sans-serif 后备，以较紧凑的形态和清楚的笔画承载中文说明。不加载远程字体；中文标题与正文不以横向压缩仿造拉丁字形，章节数字的窄高造型由本包 CSS 处理并保留可编辑文本。
- 标题与数字靠高度、粗细反差、位置和留白建立层级；正文保持可读的中文行距。字号随本包主题及内容长度安排，既不继承最早三个风格的字阶，也不因阅读用途切成另一套几何。
- 页面表面使用本包清单声明的 `light / dark / mustard / blue / red / lime`，各色都属于同一风格。名称通过共享安全 slug 校验；不能在页级注入任意颜色或套用未声明表面。

## 构图语法

| 页面任务 | 视觉组织 | 共享结构 |
|---|---|---|
| 纯文字封面 | 大标题压在下部，顶部留宽阔空白 | `type_poster` 的 cover |
| 章节转场 | 全幅单色与靠右的大数字，名称可保留为辅助内容 | `type_poster` 的 chapter |
| 介绍或立场 | 左栏标题与短文偏下，中栏长文偏上，右栏通高建筑照片 | `editorial_columns` 的 text / image |
| 团队与方法 | 一栏说明、一条窄肖像队列、一幅大图；姓名与角色独立可编辑 | `editorial_columns` 的 people |
| 价值观或原则 | 两列分组形成 2 × 2 关系，旁侧留一幅建筑照片 | `editorial_columns` 的 groups |
| 数字呈现 | 错位文字栏配显示器框内图像；说明与图框分离 | `editorial_columns` 的 image 与 monitor frame |
| 案例或观察 | 文字栏旁由多张独立照片组成紧密拼贴，按题材保持差异 | `editorial_columns` 的 gallery |

章节页和内容页按叙事形成节奏，不机械按奇偶页换色，也不要求每份稿都集齐四种颜色或全部结构。阅读稿可在相同结构中增加完整解释，也可选择其他共享布局，不规定固定一半图区或四分之一图区。

## 共享字段与独立外观

新增结构的准确字段遵循共享 [布局目录](../../white-blue-slides/references/shared-layouts.md)；本包只决定它们的外观和视觉尺度。栏目中的文字、人物信息、分组、图注和章节数字均保持可编辑；照片是独立素材，不生成整页截图。

本包使用 `header_system: style` 与自己的 `header.html`。标题由主体布局呈现时不在页头重复输出；保留语义标题，不用隐藏事实内容来制造留白。风格独立安排页头、页脚、封面尾页、字阶与边距，不使用六种 `header` 预设。

`editorial_columns` 最后一栏为纯图片或画廊时，本主题可让其向上、右、下出血，文字仍保留安全边距；显示器框的图片栏保留边框、支架和页边距。出血处理属于本主题视觉，不改共享栏目的数据顺序或其他风格几何。

照片采用真实尺度的建筑、结构、空间与人物摄影，展示时保持黑白对比和材质层次。直线、网格与物件边缘承担视觉秩序。显示器外框由共享页面结构绘制，屏幕中的图片不因此变为可编辑建筑模型；真实项目界面和图纸须由用户提供，示意素材必须明确为概念示例。

避免圆角卡片、玻璃质感、厚阴影、装饰渐变、立体微缩模型与无关图标。不为密度增加空洞分组，也不把原模板所有照片换成同一张建筑的重复裁切。
