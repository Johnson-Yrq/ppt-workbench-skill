# 制作前确认：演讲型与阅读型

此选择独立于视觉风格，所有风格入口共用。通过 [PPT 制作工作台](../../ppt-workbench/SKILL.md) 识别已确认的风格与类型，一次询问缺少的项；直接调用风格 Skill 即选定该风格。先确认用途，再决定拆页、信息密度与图文分工。

## 确认节点

新建演示稿，或将已有稿整体转换用途时，在拆页、排版或生图前确认：

> 这份 PPT 主要用于现场讲解的「演讲型」，还是发给读者独立阅读的「阅读型」？

- 用户已明确选择，或当前项目有基于用户反馈记录的模式时，直接沿用，不重复询问。明确要求“做成阅读型”本身就是确认；明确授权“你来选类型”时按目标选择并说明，无需重复索取选择。
- 未明确时询问并等待；风格也未确定时合并询问，不连续启动两次问卷。可继续读取资料、识别缺失信息，但不开始依赖密度的内容改写、版式制作或生图。无回复、模板默认值和预选项不代表确认。
- 将反馈记为根字段 `presentation_mode: "speech"` 或 `"reading"`。不要直接复制示例字段代替用户选择；也不需要额外维护一份批准表。
- 局部修字、换图和已确认范围的排版修复，继续当前稿，不重启用途问卷。旧文件缺该字段时，构建器按演讲型兼容，计划中的 `mode_recorded: false` 只表示未记录，不能据此声称用户已经选择。新制作仍须确认。
- 更新 Skill、测试两种模式或制作模式对比样例时，不把此节点误用于阻塞工具开发；它针对真实演示稿的用途选择。

本文的版式与信息密度约束用于制作；交付前按 [基本排版 QA](layout-qa.md) 逐页看图，用这些约束判断布局与密度是否合理。

## 两种密度的取舍

| 维度 | 演讲型 `speech` | 阅读型 `reading` |
|---|---|---|
| 阅读方式 | 观众跟随讲解理解 | 没有讲解也能独立理解 |
| 页面信息 | 一个结论、少量支撑点；细节可放讲稿 | 结论、机制、依据、边界同页组织，必要细节在正文 |
| 可视化 | 一个主场景或关系，少量步骤或标注 | 增加真实流程节点、比较维度、分层模块、职责和证据对应 |
| 内容结构 | 通过多页逐步展开 | 以配图和互补的可编辑内容组织完整论证；容量不足则续页 |
| 图文分工 | 配图、图表或短句突出主要结论 | 按内容关系安排配图、图表和说明，必要信息可在同页独立理解 |
| 文字层级 | 采用所选风格适合现场观看的字阶和留白 | 采用所选风格适合独立阅读的字阶，不靠统一缩字容纳更多信息 |

密度来自信息关系和可核对的内容，不以字数、图标数或装饰数量计分。不要统一缩小整页、堆满段落、增加无意义卡片，或为了“丰富”虚构功能、指标和结论。演讲型也可保留必要的复杂图；阅读型的封面、章节引入和收束仍可疏朗。

## 用途不限定排版

`presentation_mode` 只决定信息需要讲解多少、页面要保留多少依据，不限定页面必须采用某个布局、配图比例、栏目数量或统一字号。阅读型可以使用整幅照片配说明、多栏、图表、流程、文字、非对称布局及其他共享版式；按实际内容与所选风格选择，必要时拆页。图片不需要固定占页面的一半或四分之一。

页头、封面尾页、字号、边距、颜色、图片风格和图标使用由当前风格定义；内容布局、数据、可编辑组件和播放器由共享套件提供。新增风格不继承其他风格的六种页头或视觉尺度。

旧稿中的 `layout: "reading"` 及其四种 `composition` 继续兼容，作为一种可选的共享复合布局，演讲型和阅读型均可使用。只有选择该布局时，才使用它的图片数量、模块数量和几何契约。具体说明见 [reading 布局](deck-format.md#reading可选复合信息布局)，不把其中的分区比例反向解释为阅读型用途规则。

单图适合整体场景，多图适合角色、阶段或不同视角，分别承担内容作用；不重复同图凑面积。图表在有可靠数据时表达比较、趋势或构成，详见 [可编辑图表](charts.md)；缺少数据时用现有流程、矩阵、层级或文字解释，不编造指标。

## 如何把内容变成更多可视化信息

- 顺序与交接：流程节点加输入、动作、输出；异常或回退只有资料明确时才画。
- 差异与覆盖：矩阵的行是比较对象，列是相同维度；交叉单元格给出实际区别。
- 系统组成：按真实层级分组模块；有依据的依赖关系才连接，不能由位置暗示未经确认的因果。
- 责任与交付：角色、动作、交付物和验收依据形成对应表。
- 依据与边界：来源、条件、例外和待确认项与对应模块相邻，必要内容留在页面上，不能只藏在讲稿。

先从原材料确定哪些关系需要表达，再选择图形。不要把一段文字机械拆成多个框，也不要为每页固定添加流程＋矩阵＋架构。

## 套件支持

主体版式及其字段由 [共享数据契约](deck-format.md) 统一维护，所有风格都可选用；新布局先进入共享层，再由各风格表现自己的外观，不以风格 ID 限制业务布局。布局有实际容量边界，但不以固定页面比例或数字字号决定用途。新增结构保留可编辑、离线、图表与保存能力。

基本排版 QA 与诊断的结果按实际采用的布局及当前风格判断，不以旧四分区或统一字号审查所有阅读型页面。
