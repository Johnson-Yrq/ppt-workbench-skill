# 用户检查参考与风格开发验证

普通成稿由 Agent 完成 HTML 与配图后交付，导出与内容、版式、数据、实际显示检查交给用户。Agent 不自动运行逐页截图、成稿审查、PPTX 结构或 PowerPoint 检查；具体见共享 [默认交付与职责](../../white-blue-slides/references/export.md#默认交付与职责)。用户自行检查可参考共享 [检查项目](../../white-blue-slides/references/quality-check.md#用户自行检查时可参考)。下列两节仅用于开发风格包及接入共享工具，不属于每份演示稿的交付步骤。

## 风格开发的样稿阶段

核对八类页面的中文断行、字阶、黑白对比、细线、胶囊、非对称留白、照片裁切、圆形叠放和示例标识。每页文字不得相互覆盖或越出画布。图表须有单位与来源，示例数据不可当作实际成效。

检查翻页、总览、讲稿、全屏、文字编辑、保存重开与离线图片。修改图表数值后重新渲染，保存重开仍保留数据。照片逐张查看：主体与本页内容对应，横幅、圆形与满版裁切后主体完整，满版照片上的标题对比充足，无伪文字、Logo 与手部畸形，整稿调色一致。仅当工具改动涉及 PPTX 导出能力时做相应开发验证。

本包代表性样稿已获用户确认，正式清单为 ready；普通制作与同方向维护不重复索取设计批准。将来另开独立方向时，才先提供新样稿供用户确认，开发自检不能代替该批准。

## 正式共享接入的维护

本包已使用共享构建器和正式 deck 数据；历史独立样稿只作视觉转译记录。维护代码或主题时按共享 [接入规范](../../white-blue-slides/references/adding-styles.md) 检查本次受影响的无图页面、页面 surface、独立页头和共享布局，保留其他风格的外观与功能。speech 与 reading 验证信息密度；只有改动可选 reading 布局时才覆盖其分区。新增通用布局进入共享层，不重建本包专用渲染器。

按改动范围运行清单发现、计划、供图清单与相关代码测试；视觉改动才查看受影响的页面，编辑或导出改动才验证对应功能。仅改说明文档不启动成稿自检或导出。安装后确认清单可发现，旧风格不能因本包接入而变为无图或黑底。
