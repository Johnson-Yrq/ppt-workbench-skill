# 米白环线商务设计系统

本包从用户打开的商务营销计划参考提取视觉规则，来源为 [十页观察记录](../assets/reference-design/source-notes.md)。参考图片用于核对设计，不作为成品页或素材复用。原模板字体不可从预览确定，不能把本包的本地字体回退宣称为原字体。

## 视觉语言

| 项目 | 本包规则 |
|---|---|
| 画布 | 1920 × 1080，16:9；内容按共享播放器等比显示 |
| 纸色 | `#FBF6F3`，依据参考截图的色彩配置换算到 sRGB 后取值 |
| 主文字 | `#111111`；Arial、Helvetica Neue、PingFang SC 等本地无衬线回退 |
| 辅助文字与线 | 灰色正文和细线；不使用明亮强调色、厚阴影或玻璃质感 |
| 图表 | 五级受控灰色，通过主题令牌指定；颜色保持清楚区分 |
| 字阶 | 内容页大标题约 76px，常规正文 28–30px；实际以主题 CSS 为准 |
| 边距 | 内容页约 110px 横向留白；封面另设较宽标题起点 |
| 页头 | 独立页头，标题与可选摘要下接细线；线端圆点来自 CSS |
| 封面 | 左侧两行大标题，右侧重叠细线圆环，顶栏品牌与年份，底部两项署名 |
| 人像 | 独立照片在页面里圆形裁切，头像不与姓名文字合成 |
| 摄影 | 自然日光、浅木与米色石材、低饱和真实色彩；商务场景自然可信 |

圆环承担识别与信息组织作用。封面环线是装饰，画像页中心圆与连线表示关系，排期页圆形表示阶段。不要让圆面积暗示未经定义的数量，也不要为每页添加装饰照片。

## 内容与结构

本包只维护主题外观，共享组件决定语义结构和编辑行为。所有风格与两种用途均可采用本次新增布局，细节见 [共享布局](../../white-blue-slides/references/shared-layouts.md)。

| 样稿页 | 结构选择 | 本风格处理 |
|---|---|---|
| 01 封面 | `cover` 无图 | 左文右环，底部署名使用 `credits` 的独立 `title / text` 字段；样稿为两项 |
| 02 目录 | `side_index` | 两列四行，空心编号圆与清晰标签 |
| 03 营销目标 | `reading / half_diagonal` | 左上文字、右上横图、左下圆图、右下目标；复用已有复合结构 |
| 04 用户画像 | `hub_spoke` | 中心圆与四至八个关联节点；样稿为八个 |
| 05 执行节奏 | `step_row` | 二至六阶段横排；样稿为四阶段圆形时间标记 |
| 06 预算 | `chart_focus` + `pie` | 左侧判断与预算说明，右侧独立灰阶饼图 |
| 07 团队 | `editorial_columns / people` | 五人独立圆形肖像、姓名与职能，底部细线 |
| 08 渠道 | `service_cards` | 三张等高场景照片与对应说明，不加实色强调块 |
| 09 营销组合 | `table` 无图 | 四列表格，清楚的横纵细线与可编辑文字 |
| 10 KPI | `metric_cards / progress` | 三组进度条、派生百分比与解释；细线联系上下内容 |

样稿的五名成员不构成通用人数限制，三张渠道图也不构成每页图片数量规则。根据真实内容选择结构。复杂关系不在单个中心图中塞入无限节点；长表格或长说明拆页，避免缩小到不可读。

## 字体、图片与可编辑性

中文标题采用自然语义断行，避免在最后留下孤字。各类细线、连线和圆环由 CSS 绘制；标题、数字、表格、姓名、角色、图表数据和来源保留独立节点。当前仅提供 light 表面，不在项目数据里引入未声明的主题色页。

照片不做全局单色化；只通过素材选取统一光线、材质与色彩。保持人脸、手部、建筑结构和必要环境完整，圆形头像留有安全裁切空间。摄影图片使用原生背景，不执行模型素材的纸色映射。

阅读型用途补足正文与事实边界，但不改变本包的页头、字体与图像风格。普通成稿的默认交付与检查职责见 [质量参考](quality-check.md)。本方向已于 2026-10-05 获用户回复「采用」，正式状态为 ready / 1.0.0，批准范围见 [来源记录](../assets/reference-design/source-notes.md#批准状态与交付位置)；无需为同方向制作重新确认视觉。
